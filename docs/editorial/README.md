# Planeador editorial

Pipeline de contenido de Fronteando. Cada pieza (un posible artículo) vive en `piezas/<slug>.md` y aparece aquí bajo su estado. Apuntar una pieza en `idea` no implica intención de escribirla; solo pasa a `lista` cuando reúne los tres requisitos verificables: pregunta del lector, ángulo y soporte.

Las ideas de contenido viven aquí; las de producto y siguientes líneas del proyecto viven en `docs/ideas/`. Los briefs de preparación viven en `briefs/<slug>.md` (decisión D003). El gestor es el skill `gestionar-piezas`.
