# Nombres de tests

## Lecciones

- **Nombrar los tests por comportamiento: `describe` la unidad, `when` el contexto, `it` el comportamiento esperado.** Por qué: la primera suite de vitest nombró los tests con referencias internas del proyecto (CU-1, letras ZOMBIE de la suite trazada) y el usuario pidió convenciones de testing —el nombre describe qué hace la unidad, no de dónde salió el requisito.
