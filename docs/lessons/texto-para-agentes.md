# Texto para agentes

## Lecciones

- **Los campos que consume un agente se redactan como instrucción
  accionable para ese consumidor.** Por qué: las indicaciones de pausa
  salieron como «verifica que puedas decir X», que invita a una
  pregunta sí/no cuando el asistente la aplica literalmente; el
  usuario pidió la forma de la acción que el lector produce, y el
  `tema` pasó de oración nominal a un texto que explica de qué trata
  el post.
  Disparadores: agente, tema, pausa, :::pausa, indicación, frontmatter
  Origen: 20261025T211939

- **Al evaluar material que viaja a un asistente, léelo como prompt,
  no como prosa.** Por qué: el título en la ficha y la forma de las
  indicaciones salieron de leer el protocolo compuesto con los ojos
  del consumidor —un agente que quizá no puede abrir la URL—.
  Disparadores: protocolo, prompt, asistente, ficha, acompañamiento, URL
  Origen: 20261025T211940
